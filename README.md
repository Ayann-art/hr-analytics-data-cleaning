## 👥 HR Analytics – Data Cleaning & Visualization Project
## 📌 Project Overview

This project focuses on cleaning and analyzing a Human Resources (HR) dataset to better understand employee characteristics, attrition behavior, and workforce trends.
The main goal is to prepare a clean dataset and perform exploratory data analysis (EDA) supported by visualizations.

All processes were performed using Python in Google Colab.

## 📁 Dataset

Source: Kaggle – Human Resources Data Set
Link: https://www.kaggle.com/datasets/rhuebner/human-resources-data-set

File used: HRData_Set.csv (or the corresponding CSV from Kaggle)

## 🛠 Tools & Technologies

Python

Google Colab

Pandas

NumPy

Matplotlib

Seaborn

## 🧹 Data Cleaning Steps

The following preprocessing steps were applied:

Removed duplicate rows

Handled missing values

Converted columns to appropriate data types

Cleaned inconsistent and invalid values

Renamed columns for better readability

Checked for outliers

A cleaned dataset was created after these steps.

## 📊 Exploratory Data Analysis (EDA)

Basic analysis was performed to explore employee demographics and work-related factors, including:

Employee distribution by department

Attrition distribution

Age and salary distribution

Job role analysis

Relationship between salary, age, and attrition

## 📈 Visualizations

The following visualizations were created using Matplotlib and Seaborn:

Attrition Count Plot

Department-wise Employee Distribution (Bar Chart)

Age Distribution (Histogram)

Monthly Income Distribution (Histogram)

Attrition by Department (Bar Chart)

Age vs Attrition (Box Plot)

Salary vs Attrition (Box Plot)

Correlation Heatmap

## 🔍 Key Insights

Certain departments show higher attrition rates

Employees with lower income tend to leave more frequently

Younger employees show slightly higher attrition

Salary and age are important factors related to employee retention
